# Blog Archive

velog에 올린 글들을 마크다운으로 백업/정리하는 레포.

## 구성

```
blog/
├── develop-in-swift/     # Apple Develop in Swift 튜토리얼 학습 로그
│   ├── 01-app-design/
│   ├── 02-swiftui/
│   ├── 03-data-modeling/
│   ├── 04-app-development/
│   └── 05-app-distribution/
└── c-programming/        # C 프로그래밍(DASF004) 관련 글
```

새로운 주제가 생기면 최상단에 폴더를 추가한다.

## 포스트 작성 규칙

- 파일명: `NN-제목-kebab-case.md` (ex: `01-hello-swiftui.md`)
- 블로그 시작하기 전 오프닝 느낌의 글은 00번임
- 프론트매터에 title, date, tags, velog 링크 포함
